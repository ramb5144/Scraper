Max file size: 50MB

API Documentation

            

                
Endpoint: POST /api/encrypt/pdf

                
Content-Type: multipart/form-data


                
Parameters:

                
    
                    
  • pdf - PDF file (required)
    • 
                    
  • secret_key - Encryption key (optional)
    • 
                    
  • output_format - "binary" or "json" (optional)
    • 
                


                
cURL Example:

                
curl -X POST \
  -F "pdf=@document.pdf" \
  -F "secret_key=99887766" \
  -F "output_format=json" \
  http://localhost:8001/api/encrypt/pdf
