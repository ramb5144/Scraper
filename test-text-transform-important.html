Text Transform !important CSS Override Test

Test Purpose

This test verifies that the SDK can override CSS text-transform rules, even when they use !important.

Expected behavior: All text should display correctly (not gibberish) because the SDK encrypts the transformed text and then prevents the browser from re-transforming it.

Before fix: Tests with !important would show gibberish because inline styles couldn't override them.

After fix: SDK uses setProperty('text-transform', 'none', 'important') to override even !important rules.

Test 1: Normal CSS - uppercase

CSS: text-transform: uppercase;

hello world

Test 2: Normal CSS - lowercase

CSS: text-transform: lowercase;

HELLO WORLD

Test 3: Normal CSS - capitalize

CSS: text-transform: capitalize;

hello world from test

Test 4: !important CSS - uppercase (CRITICAL)

CSS: text-transform: uppercase !important;

hello world

Test 5: !important CSS - lowercase (CRITICAL)

CSS: text-transform: lowercase !important;

HELLO WORLD

Test 6: !important CSS - capitalize (CRITICAL)

CSS: text-transform: capitalize !important;

hello world from test
