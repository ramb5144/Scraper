CSS Property Detection Test

This page tests the SDK's ability to detect and handle various CSS properties that affect text rendering.

1. Text Transform Properties (Should be COMPENSATED)

Expected: Text should be encrypted AND transformed. No gibberish.
text-transform: uppercase
hello world
text-transform: lowercase
HELLO WORLD
text-transform: capitalize
hello world this is a test

2. Font Variant Properties (Should be COMPENSATED)

Expected: Text should be encrypted with uppercase transformation. No gibberish.
font-variant: small-caps
Hello World Small Caps
font-variant-caps: small-caps
Hello World Small Caps
font-variant-caps: all-small-caps
Hello World All Small Caps

3. Text Security Properties (Should be EXCLUDED)

Expected: Text should NOT be encrypted. Should show as bullets/circles in plaintext.
-webkit-text-security: disc
password123
-webkit-text-security: circle
password456

4. Writing Mode Properties (Should be EXCLUDED)

Expected: Text should NOT be encrypted. Should show vertical in plaintext.
writing-mode: vertical-rl
Vertical Text

5. Combined Properties (Should be COMPENSATED)

Expected: Text should be encrypted with BOTH transforms applied. No gibberish.
text-transform: uppercase + font-variant: small-caps
hello world combined

6. Font Feature Settings (Should be COMPENSATED if smcp/c2sc)

Expected: Text should be encrypted with uppercase transformation. No gibberish.
Note: Visual small-caps may not appear without appropriate font.
font-feature-settings: "smcp" 1
hello world features

Control Test - No CSS Properties

Expected: Text should be encrypted normally. No gibberish.
No CSS properties applied
