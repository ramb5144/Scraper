  <action>
1. Initialize npm project if package.json doesn't exist: `npm init -y`

2. Install Playwright: `npm install -D @playwright/test`

3. Install browser binaries: `npx playwright install --with-deps chromium` (chromium only for now - faster CI, add others later if needed)

4. Create playwright.config.ts with:
   - webServer block starting Flask on port 8001: `python -m flask run --port 8001`
   - reuseExistingServer: !process.env.CI (reuse locally, fresh in CI)
   - timeout: 30000 for webServer startup
   - baseURL: http://localhost:8001
   - trace: 'on-first-retry' for autonomous debugging
   - retries: 2 in CI, 0 locally
   - testDir: './tests/specs'
   - outputDir: './test-results'
   - Use only chromium project initially
   - Set permissions: ['clipboard-read', 'clipboard-write'] in use block

5. Add npm scripts to package.json:
   - "test": "playwright test"
   - "test:headed": "playwright test --headed"
   - "test:debug": "playwright test --debug"
   - "test:trace": "playwright show-trace"
  </action>

  </verify>
